# Albion Craft Calculator

Статический калькулятор крафта для Albion Online: выбор предмета, ресурсов и
параметров производства с расчётом итоговой стоимости.

- Страница: https://sunpole.github.io/260007-albion-craft-calculator/
- Репозиторий: https://github.com/sunpole/260007-albion-craft-calculator

Это браузерное приложение на HTML и Vue через публичный CDN. Текущий публичный
релиз: `0.1.0`.
